A better signal

Every score needs receipts.

The coach separates what can be observed from what cannot. Every assessment points back to an answer, and text-only sessions never invent a pronunciation score.

Inspectable by design

One typed contract. Browser to graph to report.

LangGraph.js owns the adaptive turn loop. Shared Zod contracts keep the interface honest. PostgreSQL preserves interview and checkpoint state, while provider-specific behavior stays behind evaluator adapters so local development and CI remain keyless.
