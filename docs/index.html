Control before convenience

Useful coaching should not require blind trust.

Start in deterministic demo mode without an API key. If you choose model-backed evaluation, bring your own key. The scoring rules are inspectable, your sessions can be exported or deleted, and the application never treats a coaching score as a hiring decision.
